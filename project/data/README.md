# Данные проекта

В данной папке лежит небольшая выборка из 5000 строк датасета Used Cars. Также сюда сохраняется обработанная версия датасета для обучения модели.

---

Полную версию датасета можно скачать по ссылке: https://www.kaggle.com/datasets/thedevastator/uncovering-factors-that-affect-used-car-prices
